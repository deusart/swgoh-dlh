# Concept

DLH — data lakehouse для данных игры SWGOH.

## 1. Компоненты

- **swgoh-comlink** — источник данных игры.
- **ClickHouse** — хранилище DLH.
- **Airflow** — оркестрация.
- **Python** — извлечение и нормализация данных.
- **dbt** — SQL-трансформации и витрины.

## 2. Два сервера

- **DEV** — текущий ПК: локальная проба, разработка, анализ.
- **SERVER** — второй ПК: постоянная работа сервиса; ClickHouse, Airflow, Comlink; источник истины.

## 3. Референс

- `E:\Development\swgoh` — существующий проект-ориентир.
