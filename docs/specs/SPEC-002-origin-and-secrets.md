# Origin и секреты

## 1. Контекст

Origin пока не создан: репозиторий локальный, ветка `main`, текущий тег `v0.0.4`. Версия `0.0.5` посвящена подготовке origin и места для секретов. Реальные креды в git не попадают.

Секреты нужны для:

- Comlink: URL, HMAC access/secret, если включён;
- игрок: ally code;
- ClickHouse: хост, пользователь, пароль;
- dbt: имя схемы.

## 2. Требование

### 2.1. Origin

- URL origin предоставляет пользователь.
- Remote добавляется только по явному согласию.
- Push и push тегов выполняются только по отдельному запросу.
- До первого push проверяется, что в истории нет реальных секретов.
- Основная ветка остаётся `main`.

### 2.2. Файлы секретов

В git коммитится только шаблон:

```text
.env.example
```

Реальные значения живут в:

```text
.env
```

`.env` исключён из git. На SERVER файл создаётся отдельно и не синхронизируется через git. На сервере права: только владелец.

Шаблон содержит имена переменных и пустые или безопасные значения:

| Переменная | Назначение | Секрет |
|---|---|---|
| `COMLINK_URL` | адрес сервиса Comlink | нет |
| `COMLINK_ACCESS_KEY` | HMAC public key | да |
| `COMLINK_SECRET_KEY` | HMAC secret | да |
| `SWGOH_ALLY_CODE` | код игрока | персональный, не коммитить |
| `CLICKHOUSE_HOST` | хост ClickHouse | нет |
| `CLICKHOUSE_PORT` | порт | нет |
| `CLICKHOUSE_USER` | пользователь | нет |
| `CLICKHOUSE_PASSWORD` | пароль | да |
| `DBT_SCHEMA` | схема dbt | нет |

### 2.3. Проверка перед push

- `git grep` по именам переменных не находит реальных значений.
- `git log -p` не содержит ключей, паролей и ally code.
- `.env` отсутствует в индексе и истории.
- В origin попадает только `.env.example`.

### 2.4. Ограничения

- Новые инструменты не добавляются.
- Менеджер секретов, vault и CI-секреты не вводятся на этом этапе.
- Реальные креды не передаются через git, чат или документацию.

## 3. Критерии

- [ ] В репозитории есть `.env.example` с именами переменных и без реальных значений.
- [ ] `.env` исключён из git.
- [ ] В истории нет реальных секретов.
- [ ] Origin URL согласован и remote добавлен только после этого.
- [ ] Первый push выполнен только по явному запросу.
- [ ] `node tools/check-docs.mjs --strict` возвращает 0.

## 4. Что не входит

- Создание origin без URL и согласия.
- Реальные ключи, пароли и ally code в git.
- CI-секреты и GitHub Actions.
- Внешний менеджер секретов.
- Настройка SERVER и его `.env`.
